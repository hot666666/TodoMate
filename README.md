# TodoMate

TodoMate는 사용자들이 그룹을 통해 오늘의 할 일들을 실시간으로 공유할 수 있습니다.

## 업데이트 체크리스트

- [x] Update dependencies
- [x] Pre-commit hook setup
- [x] Entity migration
- [x] Domain Layer
- [x] Data Layer
- [x] Presentation Layer
- [x] Widget
- [x] 최초 앱 실행 시 세팅 처리 / 기존 사용 캐시 초기화
- [x] Presentation Layer 정리
- [ ] 유저 처리
- [ ] 자동화 파이프라인(issue->pr->배포)

## 커밋 메시지 컨벤션

```
<type>(optional scope): <subject>

feat: 사용자 로그인 기능 추가
fix(todo): 삭제 기능에서 null 오류 수정
chore: 프로젝트 의존성 업데이트
docs(readme): 사용법 설명 추가
```
