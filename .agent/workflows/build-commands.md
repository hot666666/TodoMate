# Build & Test Commands

## Environment
- **Xcode**: 26.0+
- **OS**: macOS

## Commands

### Build
Build the project.
```bash
// turbo
just build
```

### Test (Full Suite)
Run the entire test suite. During development, it is recommended to run only relevant tests as per `development-workflow.md`.
```bash
// turbo
just test
```
